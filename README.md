# Shell-3D 🐚🎨

**Shell-3D** — интерактивный 3D-вьюер моделей в консоли (терминале) на языке **Rust**. 
Использует математику 3D-проекций, Z-буфер для обработки глубины, задержку от спама клавиш (Debounce) и 3 режима отображения.

Приложение скомпилировано со статическим связыванием (`x86_64-pc-windows-gnu` + MinGW), поэтому работает **полностью автономно** без необходимости установки Visual Studio или системных C++ DLL.

---

## 🚀 Особенности

- 📦 **Поддержка форматов**: загрузка любых 3D-файлов `.obj` (Wavefront) и `.stl` (ASCII & Binary).
- 🎲 **Встроенные 3D-примитивы**: куб, пирамида, UV-сфера, тор (пончик).
- 🎮 **Интерактивное управление**: плавная регулировка поворотов стрелками без случайных двойных срабатываний.
- 💡 **Z-Buffer & 3 Режима отображения**:
  1. `ASCII Solid` (`" .:-=+*#%@"`)
  2. `Unicode Block` (`" ░▒▓█"`)
  3. `Wireframe` (проволочный каркас)
- 🎯 **Авто-центрирование**: автоматический расчёт центроида и масштабирование модели под размеры терминала.

## 🎮 Управление (Controls)

| Клавиши | Действие |
| :--- | :--- |
| **Стрелка Влево / Вправо** | Вращение модели вокруг вертикальной оси Y |
| **Стрелка Вверх / Вниз** | Вращение модели вокруг горизонтальной оси X |
| **Q / E** | Вращение модели вокруг оси Z |
| **`+` / `-`** или **W / S** | Приближение / отдаление (Zoom In / Out) |
| **M** | Переключение режимов: **ASCII Solid** $\to$ **Unicode Block (█░▒)** $\to$ **Wireframe** |
| **P** | Переключение встроенных 3D-примитивов (Куб $\to$ Пирамида $\to$ Сфера $\to$ Тор) |
| **R** | Сброс положения и масштаба камеры |
| **ESC** или **Ctrl+C** | Чистый выход из программы с восстановлением терминала |

## 🛠️ Запуск и Использование

### 1. Открытие 3D-файла (`.obj` или `.stl`)

Для указания файла используйте краткий флаг **`-f`** или полный флаг **`--file`**:

```bash
# Загрузка файла .obj с флагом -f
cargo run --release -- -f models/cube.obj

# Загрузка через полный флаг --file
cargo run --release -- --file models/human.obj

# Загрузка файла .stl
cargo run --release -- -f models/pyramid.stl

# Запуск скомпилированного .exe файла напрямую:
.\target\release\shell-3d.exe -f models/human.obj
```

### 2. Запуск со встроенными 3D-фигурами (без файлов)

Если файл не указан, можно выбрать один из встроенных примитивов с помощью флага `-p` или `--primitive`:

```bash
# Куб (по умолчанию)
cargo run --release

# Тор (пончик)
cargo run --release -- -p torus

# Сфера
cargo run --release -- --primitive sphere
```

Проект настроен на сборку через **Rust GNU toolchain** со статическим связыванием библиотеки C runtime (`-static -static-libgcc`), зафиксированным в [`.cargo/config.toml`](file:///c:/Users/karag/CODES/shell-3d/.cargo/config.toml).

```bash
# Сборка готового бинарника
cargo build --release
```

Готовый файл располагается по пути: `target/release/shell-3d.exe`.
